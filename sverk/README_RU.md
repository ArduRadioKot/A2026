# Проект Sverk

Sverk — отдельный проект с соревнований по робототехнике. В нём находятся самостоятельные эксперименты для дрона, ровера и компьютерного зрения на основе YOLO.

## Структура проекта

- `drone/` — программы управления дроном и эксперименты с полётами.
- `roverr/` — программы управления ровером, включая эксперименты со светодиодной лентой и движением.
- `yolo/` — эксперименты с YOLO и файлы моделей.
- `aruco_field_6x6_map.txt` — карта поля ArUco 6x6 или справочник расположения маркеров.

## Основные технологии

- Python 3
- Интеграции с управлением роботами и транспортными платформами
- OpenCV и компьютерное зрение
- Карты ArUco-маркеров
- Детекция объектов YOLO

## Запуск

В каталогах находятся независимые соревновательные скрипты. Единого лаунчера у проекта нет. Перед запуском изучите импорты и настройки оборудования выбранного файла и подключите только необходимое для эксперимента оборудование.

Обычный запуск:

```bash
python path/to/script.py
```

Программы движения и полёта следует запускать только на контролируемой площадке с ручной аварийной остановкой. Перед экспериментами с YOLO проверьте пути к моделям и настройки камеры.

## Статус

Проект сохранён как материал с соревнований и исследований. Скрипты могут зависеть от локального оборудования, драйверов, моделей и настроек окружения.
