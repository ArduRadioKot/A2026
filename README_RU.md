# Проекты с соревнований A2026

В этом репозитории находятся три независимых проекта по робототехнике и автономным системам, разработанных для соревнований:

- [`anpa/`](anpa/) — автономные полёты, ArUco, лазерная связь, видеотрансляция и эксперименты с ИИ.
- [`geoscan/`](geoscan/) — навигация по камере, распознавание ArUco и YOLO, видеотрансляция и прототипы управления полётом.
- [`sverk/`](sverk/) — отдельные эксперименты с дроном, ровером и компьютерным зрением на основе YOLO.

Каждый каталог является отдельным архивом проекта. Общего лаунчера и единого списка зависимостей нет: интерфейсы оборудования, настройки камер, пути к моделям и требования к окружению могут отличаться у разных скриптов.

## Общие замечания

Код сохранён как материал с соревнований и исследований. Перед запуском скрипта изучите его импорты и настройки и подключите только необходимое оборудование. Программы полёта и движения следует испытывать только на контролируемой площадке с ручной аварийной остановкой.

Большинство скриптов можно запускать напрямую через Python:

```bash
python path/to/script.py
```

Точный набор Python-пакетов, ROS, камер, роботов, дронов и обученных моделей зависит от выбранного скрипта.
